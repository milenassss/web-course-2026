# Объяснение проекта

## Компоненты и модули

- src/main.jsx подключает React к странице.
- App.jsx хранит единственный массив задач, фильтры и обработчики.
- TodoForm хранит текст новой задачи и выбранный статус локально. Вызывает onAdd после валидации. Добавление работает по Enter и кнопке.
- Filters получает настройки через props, вызывает onChange. Варианты фильтров и сортировок берутся из реестров.
- Stats получает числа: всего, осталось и выполнено.
- TodoList получает видимый массив и передаёт задачи в TodoItem с key, равным уникальному id.
- TodoItem хранит локально только режим редактирования, черновик и ошибку. Данные задачи получает из App; изменение статуса, удаление и сохранение текста вызывают переданные функции.
- utils/tasks.js — валидация, статистика, фильтрация и сортировки.
- services/storage.js — чтение, проверка и запись localStorage.

## Состояние и сохранение

Задача содержит id, text, completed и createdAt. Идентификаторы создаются через crypto.randomUUID, время добавления — Date.now. При редактировании дата добавления не изменяется.

Начальное состояние читается из localStorage при инициализации. Проверяется структура записей и уникальность id. useEffect сохраняет задачи после каждого изменения. Ошибка записи отображается пользователю; текущий список остаётся доступен в памяти. Данные отдельные для каждого браузера и адреса сайта.

## Расширение фильтров и сортировок

STATUS_FILTERS — реестр объектов с value, label, test. Для нового статусного фильтра добавьте объект с предикатом test.
SORT_OPTIONS — реестр объектов с value, label, compare. Для новой сортировки добавьте объект с функцией сравнения compare.
Filters автоматически отобразит новые варианты, TodoList менять не нужно.

Фильтр статуса и поиск по подстроке применяются совместно. Сортируется копия [...tasks], исходный массив не мутирует.

## Мемоизация

Ввод в TodoForm меняет только локальное состояние формы и не перерисовывает App и список.

useCallback сохраняет ссылки на обработчики. Функциональный setTasks(current => ...) даёт доступ к актуальному состоянию без зависимости обработчиков от tasks.

useMemo пересчитывает видимый список только при изменении задач или фильтров. Статистика пересчитывается только при изменении задач.

memo оборачивает компоненты. При изменении одной задачи map создаёт новый объект только для неё, остальные объекты сохраняют ссылки. Неизменённые TodoItem получают прежние props и могут пропустить рендер. Список и статистика при изменениях закономерно обновляются.

В режиме разработки StrictMode может вызывать функции компонентов дважды. Это проверка React. В React DevTools Profiler можно проверить, что ввод в форму не обновляет TodoList, а переключение одной задачи не перерисовывает остальные карточки.

## Проверка вручную

1. Добавить задачу по Enter и вторую кнопкой с отметкой «Уже выполнена».
2. Отправить пустой текст и пробелы — получить ошибку.
3. Переключить чекбокс, проверить фильтры и счётчики.
4. Найти подстроку без учёта регистра.
5. Сравнить алфавитную сортировку и оба порядка даты.
6. Изменить текст, отменить черновик, удалить задачу.
7. Перезагрузить страницу — список восстанавливается.
