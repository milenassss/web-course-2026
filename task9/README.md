# Лабораторные 8–9 — Todo на React

React + Vite: добавление задач с выбором статуса, редактирование, выполнение, удаление, фильтры по статусу и тексту, сортировка по алфавиту и дате. Задачи сохраняются в localStorage при каждом изменении через useEffect.
Запуск: установить Node.js 22.12+ или совместимую более новую LTS, открыть терминал в task8-9, выполнить npm install, затем npm run dev. Открыть адрес Vite (обычно http://localhost:5173).
Проверки: npm run lint и npm run build. Просмотр сборки: npm run preview. Live Server и двойной щелчок не обрабатывают JSX: нужен Vite.

Подробности в EXPLANATION.md. Реализованы обязательные пункты 8–9. Опциональные json-server и импорт из JSONPlaceholder не подключены.

## Запуск на Windows двойным щелчком

Извлечь архив целиком и открыть START.bat. Нужен установленный Node.js LTS; при его отсутствии батник покажет адрес загрузки. Первый запуск требует интернета и автоматически выполняет npm ci. Затем запускается Vite на http://127.0.0.1:5173 и открывается браузер. Чёрное окно нужно оставить открытым. Фиксированный порт и strictPort сохраняют один адрес для localStorage: если порт занят, закройте предыдущий экземпляр. Подробности — в файле «СНАЧАЛА ПРОЧИТАЙ.txt».
