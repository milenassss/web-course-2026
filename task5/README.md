# Лабораторная работа №5 - Simon

Реализована игра Simon с последовательностью, которая удлиняется после каждого успешного раунда. Во время показа кнопки заблокированы, а все таймеры очищаются при ошибке или перезапуске.

Для запуска откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.
