КАК ОТКРЫТЬ ZEN MONEY НА WINDOWS

Подходит для обычных компьютеров с Windows 10 или 11, 64 бит (Intel/AMD).
Ничего устанавливать и вводить команды не нужно.

ПЕРВЫЙ ЗАПУСК
1. Сохрани архив Zen-Money-Windows.zip на компьютер.
2. Нажми на архив правой кнопкой мыши → «Извлечь всё» → «Извлечь».
3. Открой извлечённую папку Zen-Money-Windows.
4. Найди START.bat (может отображаться просто как START).
   Дважды нажми на него. Откроются чёрное окно и страница в браузере.
5. Чёрное окно оставь открытым, пока пользуешься программой.

Если браузер не открылся, введи в его адресную строку:
http://localhost:3001

Не запускай START прямо внутри архива. Сначала извлеки всю папку.
Не нужно открывать index.html, устанавливать VS Code или Node.js.
Для работы этой сборки интернет не требуется.

КАК ЗАКРЫТЬ
Закрой вкладку браузера и чёрное окно крестиком.

КАК ОТКРЫТЬ СНОВА
Открой ту же извлечённую папку и дважды нажми START.
Не распаковывай архив заново каждый раз: записи сохраняются в этой папке.

ГДЕ ДАННЫЕ
Операции и категории сохраняются в db.json рядом с START.
Не удаляй этот файл. Чтобы сделать резервную копию, закрой программу
и скопируй всю папку в другое место. Файл db.backup.json — копия данных
на момент первого запуска, а не постоянно обновляемая резервная копия.
При первой загрузке есть несколько учебных операций. Их можно удалить
кнопками «Удалить» в самой программе, если хочешь вести свой учёт.

ЕСЛИ НЕ РАБОТАЕТ
— Есть сообщение «Port 3001 is already in use»: закрой старое чёрное
  окно программы. Если не помогло, перезагрузи компьютер и запусти START.
— Есть сообщение про runtime: извлеки архив целиком, а не один START.
— Windows или антивирус блокирует запуск: пришли отправителю фото
  сообщения и дождись помощи.
— Любая другая ошибка: сфотографируй чёрное окно и отправь фото тому,
  кто передал тебе программу. Файлы внутри папки менять не нужно.
