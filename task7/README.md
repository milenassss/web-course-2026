# Лабораторная работа №7

Лента JSONPlaceholder: порции по 10 постов, бесконечная прокрутка, поиск по загруженным заголовкам с debounce 300 мс, индикатор загрузки и повтор при сетевой ошибке.
Запуск из папки task7: `python3 -m http.server 8000`, затем открыть http://localhost:8000. Для API нужен интернет; библиотеки и сборка не требуются.
Код разделён на именованные функции в script.js: loadNextPage — запрос и состояние, render — фильтрация и интерфейс, createPostCard — карточка, debounce — задержка поиска.
