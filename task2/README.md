# Whitepace — адаптивный лендинг

Учебный проект для лабораторной работы №2 по адаптивной вёрстке. Страница выполнена на основе макета Whitepace из Figma.

## Макет

[Whitepace — SaaS Landing Page в Figma](https://www.figma.com/design/3d9YTQmY3f9ywUN9B0V9eZ/Whitepace---SaaS-Landing-Page--Community-?node-id=5-34420&p=f)

## Использованные технологии

- HTML5;
- CSS3;
- CSS Grid для основной структуры страницы;
- Flexbox для расположения элементов внутри компонентов;
- подход Mobile First;
- медиазапросы для планшетов и компьютеров.

JavaScript в проекте не используется. По условию работы мобильное меню должно только визуально превращаться в бургер.

## Адаптивность

В проекте предусмотрены три диапазона ширины экрана:

- мобильные устройства — до 767px;
- планшеты — от 768px до 1199px;
- компьютеры — от 1200px.

Базовые стили написаны для мобильных устройств. Более широкие версии подключаются через `min-width`.

## Структура проекта

```text
task2/
├── img/
│   └── logo.svg
├── index.html
├── style.css
└── README.md
```

- `index.html` — структура лендинга;
- `style.css` — оформление и адаптивная вёрстка;
- `img/logo.svg` — изображение логотипа.

## Как запустить

Дополнительная установка не требуется. Достаточно открыть файл `index.html` в браузере.

Также проект можно запустить через локальный сервер:

```bash
python3 -m http.server 8000
```

После запуска нужно открыть в браузере адрес `http://localhost:8000`.

## Реализованные элементы

- адаптивная шапка и мобильный бургер;
- hero-секция с декоративным макетом интерфейса;
- адаптивная сетка тарифных карточек;
- форма обратной связи;
- подвал сайта;
- hover-эффекты и плавные переходы;
- минимальный размер интерактивных элементов 44×44px;
- защита от горизонтальной прокрутки.

Поле Email является обычным текстовым полем без проверки формата, поскольку валидация формы не входит в требования лабораторной работы.
